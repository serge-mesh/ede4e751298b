# Picket AdGuard-parity corpus (crates/picket-rules/PARITY.md §2): hand-written rule groups with
# the decision urlfilter v0.23 and AdGuard Home v0.107.80's matchHost / processDNSRewrites give,
# from urlfilter's DNS engine tests and rule docs. Each group is one bundle (one filter list).
# tests/parity_corpus.rs checks Picket against every line without Go; the differential test
# (tests/urlfilter_parity.rs) runs every group through the urlfilter oracle and fails if a written
# expectation isn't urlfilter's own.
#
#   = <title>                      starts a group
#   r <rule>                       a rule line (adblock format)
#   e <name> <outcome> [opts]      a query name and the expected outcome
#   i <address> <outcome> [opts]   an answer address and the expected outcome
#   m <rule> ~~ <names it matches> ~~ <names it doesn't>
#                                  a one-rule group (matching = block, or exception for @@);
#                                  IP addresses are matched as answer addresses
#
# Outcomes: block | exception | none | hostmap[=ip,...] | a=ip[,ip] | aaaa=ip[,ip] |
#           cname=name | rcode=NAME | nodata   (a=, aaaa= and nodata: the records of the
#           query's type)
# Options:  qtype=TYPE  ip=client-ip  client="client name"  tags=a,b  decisive="rule text"
#           (default: qtype A, no client)
#
# Groups marked "(picket)" check a deviation the spec names (rules.md §1–§3) instead of AdGuard;
# the oracle doesn't check them.

= ||d^ matches the name and its subdomains
r ||example.org^
e example.org block
e sub.example.org block
e a.b.example.org block
e badexample.org none
e example.org.evil.com none
e example.com none

= |d^ matches the name only
r |example.org^
e example.org block
e sub.example.org none

= ://d^ matches the name only
r ://example.org^
e example.org block
e sub.example.org none

= ://d without a separator is a prefix on http://host
r ://example.org
e example.org block
e example.org.au block

= *.d^ and .d^ match subdomains only
r *.example.org^
r .example.net^

e example.org none
e x.y.example.net block
e example.net none

= a host rule matches the exact name
r example.org

e sub.example.org none

e sub.example2.org block

= ||d| ends at the name
r ||example3.org|
