## Testing

- `cargo test --workspace` runs everything that needs no extra tools.
- Opt-in: `PICKET_HELPER_KERNEL_TESTS=1` (helper against the real kernel in `unshare -rn`), `cargo test -p picket-edge-update -- --ignored systemd_analyze_verify` (needs systemd), `PICKET_URLFILTER_ORACLE=<binary>` (AdGuard parity; see `crates/picket-rules/PARITY.md`).
- Fuzzing: one cargo-fuzz crate per component under `fuzz/<component>/`; run with `cargo +nightly fuzz run --fuzz-dir fuzz/<component> <target>`.

## aarch64 edge build and cargo deny

- `scripts/check-edge-aarch64.sh` (CI job `edge-aarch64`) builds picket-edge, picket-edge-helper and picket-edge-update in the release profile with `cargo zigbuild --target aarch64-unknown-linux-gnu.2.41` (zig 0.16.0 and cargo-zigbuild 0.24.1, pinned in `ci.yml`). It fails if a binary isn't aarch64, needs a `GLIBC_x.y` above 2.41 (`objdump -T`), or links anything but libc, libm, libgcc_s and ld-linux-aarch64. aws-lc-sys cross-compiles through zig with no extra settings. All three binaries currently need at most GLIBC_2.39.
- `scripts/check-deny.sh` (CI job `deny`, cargo-deny 0.22.1) runs `cargo deny --all-features --locked check` with `deny.toml`: RustSec advisories (unmaintained, unsound and yanked crates included), a permissive licence allowlist, duplicate versions (listed skips) and wildcards banned, ring and openssl-sys banned, crates.io only. No advisory is excepted: `url` is 2.5.9 (RUSTSEC-2026-0592), and timestamps use jiff, so chrono (RUSTSEC-2026-0543, unmaintained) is out of the graph.
- chrono 0.4.45 is still listed in `Cargo.lock` and `fuzz/{core,edge,lookup}/Cargo.lock` as croner 5's unused optional dependency. It is never built (`cargo tree -i chrono` is empty; cargo deny passes), but lockfile scanners (cargo-audit, osv-scanner, trivy) still report RUSTSEC-2026-0543 for it.
