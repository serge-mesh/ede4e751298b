Picket

Options

Edge

The edge's DoH listener with the bypass API ("api": true), e.g. https://dns.home.arpa:9853 on the UCG-Fiber.

Opened by "Allow permanently…"; nothing is ever sent to it.

This browser must trust the LAN CA root: download it from core's UI. In Firefox, import it under Settings → Privacy & Security → Certificates → View Certificates → Authorities.

Blocked sub-resources

Needs access to the requests of every site. The extension still sends nothing anywhere but the edge: a failed request's host name is probed at the edge, which already resolves it.

Browser lists

Picket also publishes the browser rules DNS can't apply as filter lists. Subscribe to one in this browser's content blocker.

Over HTTPS the browser must trust the LAN CA; otherwise use core's plain-HTTP port.

Brave

Open brave://settings/shields/filters, choose Add custom filter list and paste the URL. Brave's built-in lists stay on; a subscribed list's network exceptions cancel built-in blocks, but its site-specific cosmetic exceptions don't.

Firefox

In uBlock Origin's dashboard, open Filter lists, tick Import… under Custom, paste the URL and press Apply changes. All of uBlock Origin's lists share one engine, so every exception applies to every list.

With the profile list, a temporary allow also unblocks the name in the browser; with the full list, the browser still blocks it.
